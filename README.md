# Senimatik

A next-generation digital art licensing marketplace where creators earn fairly and collectors get verifiable ownership rights for their purchases. Built on Solana with transparent on-chain royalties and flexible license options.

**[🌐 Live Demo](#) · [📚 Docs](./docs) · [🐛 Report Issues](https://github.com/senimatik/senimatik/issues)**

---

## 🎨 What is Senimatik?

Senimatik is a **verified creator licensing marketplace** that solves the digital art problem:

- **For Creators:** Upload your art, set flexible license types (Personal Use, Commercial, Limited Editions), earn royalties on every resale
- **For Collectors:** Buy with confidence. Get verifiable proof of license ownership on-chain. Use art commercially with automatic royalty splits
- **For Everyone:** Combat art theft with creator verification. Get clear, enforceable usage rights instead of ambiguous "right-click saves"

### Why Senimatik?

| Problem | Solution |
|---------|----------|
| No proof of ownership | Verifiable License NFTs on Solana blockchain |
| Stolen artwork everywhere | Creator verification (portfolio + application review) |
| Unclear commercial rights | Explicit license types with fine-grained permissions |
| Manual royalty tracking | On-chain royalties flowing automatically to creators |
| Fragmented marketplaces | Unified platform for all art license types |

## 🚀 Getting Started

### Prerequisites
- **Node.js** 18+ and npm/pnpm
- **Solana Wallet** (Phantom, Solflare, or Coinbase Wallet)
- **Convex Account** (get at [convex.dev](https://convex.dev))
- **Cloudflare R2** account for file uploads (optional for dev)

---

### First Steps
- **Create Account** — Connect wallet via Solana Wallet Adapter
- **Apply as Creator** — Fill out application form (auto-approved in dev)
- **Create Artwork** — Go through 6-step creation flow
- **Browse Discover** — See all created artworks
- **View Studio** — Dashboard with your listings
